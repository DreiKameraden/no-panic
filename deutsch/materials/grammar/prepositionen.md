
# Пространственные и временные предлоги в немецком языке

## I. Пространственные предлоги

### 1. Смешанные предлоги (Wechselpräpositionen)

**Правило:** *Wo?* (Где?) → **Dativ** | *Wohin?* (Куда?) → **Akkusativ**

| Предлог     | Значение              | Где? (Dativ)           | Куда? (Akkusativ)    |
| ------------------ | ----------------------------- | ------------------------- | ------------------------ |
| **in**       | в, внутри              | *in der Schule*         | *in die Schule*        |
| **an**       | на (вертикаль), у | *an der Wand*           | *an die Wand*          |
| **auf**      | на (горизонталь) | *auf dem Tisch*         | *auf den Tisch*        |
| **über**    | над                        | *über dem Tisch*       | *über den Tisch*      |
| **unter**    | под                        | *unter dem Stuhl*       | *unter den Stuhl*      |
| **vor**      | перед                    | *vor dem Haus*          | *vor das Haus*         |
| **hinter**   | за                          | *hinter dem Haus*       | *hinter das Haus*      |
| **neben**    | рядом                    | *neben der Bank*        | *neben die Bank*       |
| **zwischen** | между                    | *zwischen den Büchern* | *zwischen die Bücher* |

**Слияния с артиклем:** *im, am, ins, ans, aufs*

---

### 2. Предлоги только с Dativ (пространство)

| Предлог       | Значение             | Пример               | Слияние |
| -------------------- | ---------------------------- | -------------------------- | -------------- |
| **aus**        | из (внутри)          | *aus dem Zimmer*         | —             |
| **bei**        | у, возле               | *bei dem Arzt*           | *beim*       |
| **nach**       | в (город/страна) | *nach Berlin*            | —             |
| **von**        | от, с                     | *von dem Bahnhof*        | *vom*        |
| **zu**         | к                           | *zu dem Arzt*            | *zum / zur*  |
| **gegenüber** | напротив             | *dem Bahnhof gegenüber* | —             |
| **außer**     | вне                       | *außer dem Haus*        | —             |

---

### 3. Предлоги только с Akkusativ (пространство)

| Предлог    | Значение                | Пример          |
| ----------------- | ------------------------------- | --------------------- |
| **durch**   | через, сквозь        | *durch den Park*    |
| **um**      | вокруг                    | *um das Haus*       |
| **gegen**   | по направлению к  | *gegen die Wand*    |
| **entlang** | вдоль (после сущ.) | *den Fluss entlang* |

---

### 4. Дополнительные пространственные предлоги (реже, но нужны)

| Предлог       | Значение                  | Падеж      | Пример             |
| -------------------- | --------------------------------- | --------------- | ------------------------ |
| **innerhalb**  | внутри, в пределах | Dativ / Genitiv | *innerhalb der Stadt*  |
| **außerhalb** | за пределами           | Dativ / Genitiv | *außerhalb der Stadt* |
| **oberhalb**   | над, выше                  | Genitiv         | *oberhalb des Flusses* |
| **unterhalb**  | под, ниже                  | Genitiv         | *unterhalb des Berges* |
| **inmitten**   | посреди                    | Genitiv         | *inmitten des Zimmers* |
| **diesseits**  | по эту сторону        | Genitiv         | *diesseits der Grenze* |
| **jenseits**   | по ту сторону          | Genitiv         | *jenseits der Grenze*  |
| **längs**     | вдоль                        | Genitiv / Dativ | *längs des Flusses*   |

## II. Временные предлоги

### 1. Временные предлоги с Dativ

| Предлог | Когда используется        | Пример                             |
| -------------- | ------------------------------------------ | ---------------------------------------- |
| **an**   | дни, даты, части дня        | *am Montag, am 3. Mai, am Morgen*      |
| **in**   | месяцы, сезоны, «через» | *im März, im Winter, in einer Stunde* |
| **vor**  | «тому назад», «до»          | *vor einem Jahr, vor dem Essen*        |
| **nach** | «после»                             | *nach der Arbeit*                      |
| **seit** | «с» (продолжается)          | *seit einem Monat*                     |
| **bei**  | «во время»                        | *beim Essen*                           |
| **ab**   | «начиная с» (будущее)     | *ab morgen*                            |
| **zu**   | праздники                         | *zu Weihnachten*                       |

---

### 2. Временные предлоги с Akkusativ

| Предлог  | Когда используется            | Пример        |
| --------------- | ---------------------------------------------- | ------------------- |
| **um**    | точное время                        | *um 8 Uhr*        |
| **bis**   | «до» (конечный момент)       | *bis Montag*      |
| **für**  | «на» (длительность)            | *für eine Woche* |
| **gegen** | «около» (примерное время) | *gegen 17 Uhr*    |

---

### 3. Особые случаи

| Случай                      | Правило                            | Пример               |
| --------------------------------- | ----------------------------------------- | -------------------------- |
| Год без слова *Jahr* | без предлога и артикля | *1918 endete der Krieg.* |
| Год со словом *Jahr* | *im Jahr*                               | *im Jahr 1918*           |

---

## III. Итоговая шпаргалка

| Категория                                      | Предлоги                                        |
| ------------------------------------------------------- | ------------------------------------------------------- |
| **Только Dativ**                            | aus, bei, mit, nach, seit, von, zu, außer, gegenüber  |
| **Только Akkusativ**                        | durch, für, gegen, ohne, um, bis, entlang              |
| **Смешанные (Wo? = Dat / Wohin? = Akk)** | an, auf, hinter, in, neben, über, unter, vor, zwischen |
| **Время + Dativ**                            | an, in, vor, nach, seit, bei, ab, zu                    |
| **Время + Akkusativ**                        | um, bis, für, gegen                                    |
