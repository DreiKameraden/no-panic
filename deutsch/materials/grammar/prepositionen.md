# Пространственные и временные предлоги в немецком языке (полный конспект)

## I. Пространственные предлоги

### 1. Смешанные предлоги (Wechselpräpositionen)

**Правило:** *Wo?* (Где?) → **Dativ** | *Wohin?* (Куда?) → **Akkusativ**

| Предлог     | Значение              | Где? (Dativ)           | Куда? (Akkusativ)    |
| ------------------ | ----------------------------- | ------------------------- | ------------------------ |
| **in**       | в, внутри              | *in der Schule*         | *in die Schule*        |
| **an**       | на (вертикаль), у | *an der Wand*           | *an die Wand*          |
| **auf**      | на (горизонталь) | *auf dem Tisch*         | *auf den Tisch*        |
| **über**    | над                        | *über dem Tisch*       | *über den Tisch*      |
| **unter**    | под                        | *unter dem Stuhl*       | *unter den Stuhl*      |
| **vor**      | перед                    | *vor dem Haus*          | *vor das Haus*         |
| **hinter**   | за                          | *hinter dem Haus*       | *hinter das Haus*      |
| **neben**    | рядом                    | *neben der Bank*        | *neben die Bank*       |
| **zwischen** | между                    | *zwischen den Büchern* | *zwischen die Bücher* |

**Слияния с артиклем:** *im, am, ins, ans, aufs*

**Важное уточнение:** выбор падежа зависит не только от вопроса, но и от **глагола**. Глаголы движения/изменения положения (*legen, stellen, setzen, gehen, fahren*) требуют Akkusativ. Глаголы состояния (*liegen, stehen, sitzen, hängen*) — Dativ .

---

### 2. Предлоги только с Dativ (пространство)

| Предлог       | Значение                                   | Пример               | Слияние |
| -------------------- | -------------------------------------------------- | -------------------------- | -------------- |
| **aus**        | из (внутри)                                | *aus dem Zimmer*         | —             |
| **bei**        | у, возле                                     | *bei dem Arzt*           | *beim*       |
| **nach**       | в (город/страна без артикля) | *nach Berlin*            | —             |
| **von**        | от, с                                           | *von dem Bahnhof*        | *vom*        |
| **zu**         | к (люди, учреждения)                | *zu dem Arzt*            | *zum / zur*  |
| **gegenüber** | напротив                                   | *dem Bahnhof gegenüber* | —             |
| **außer**     | вне, кроме                                 | *außer dem Haus*        | —             |

---

### 3. Предлоги только с Akkusativ (пространство)

| Предлог    | Значение                             | Пример          |
| ----------------- | -------------------------------------------- | --------------------- |
| **durch**   | через, сквозь                     | *durch den Park*    |
| **um**      | вокруг                                 | *um das Haus*       |
| **gegen**   | по направлению к               | *gegen die Wand*    |
| **entlang** | вдоль (обычно после сущ.) | *den Fluss entlang* |

### 4. Genitiv-Präpositionen (пространство и не только)

Эти предлоги в письменной речи требуют **Genitiv**, но в разговорной всё чаще допускают Dativ. Для экзаменов (B1/B2) лучше использовать Genitiv .

| Предлог       | Значение                  | Пример             |
| -------------------- | --------------------------------- | ------------------------ |
| **innerhalb**  | внутри, в пределах | *innerhalb der Stadt*  |
| **außerhalb** | за пределами           | *außerhalb der Stadt* |
| **oberhalb**   | над, выше                  | *oberhalb des Flusses* |
| **unterhalb**  | под, ниже                  | *unterhalb des Berges* |
| **inmitten**   | посреди                    | *inmitten des Zimmers* |
| **diesseits**  | по эту сторону        | *diesseits der Grenze* |
| **jenseits**   | по ту сторону          | *jenseits der Grenze*  |
| **längs**     | вдоль                        | *längs des Flusses*   |
| **nahe**       | вблизи                      | *nahe der Stadt*       |

**Частотные Genitiv-предлоги не-пространственного значения (тоже нужны):**

- **wegen** — из-за: *wegen des Wetters*
- **trotz** — несмотря на: *trotz des Regens*
- **während** — во время: *während der Ferien*
- **statt / anstatt** — вместо: *statt des Autos*

**Разговорное послабление:** *wegen dem Wetter, trotz dem Regen, während dem Vortrag* — в устной речи допустимо, но не для письменных экзаменов .

---

### 5. Ключевое различие: nach / zu / in (направление)

Это одна из самых частых ошибок. Правило зависит от **типа места** и **наличия артикля** :

| Тип места                                          | Предлог       | Пример                                   |
| ---------------------------------------------------------- | -------------------- | ---------------------------------------------- |
| Города, страны **без артикля** | **nach**       | *nach Berlin, nach Österreich*              |
| Страны **с артиклем**                 | **in + Akk.**  | *in die Schweiz, in die Türkei, in die USA* |
| Люди, профессии, учреждения         | **zu**         | *zu Peter, zum Arzt, zur Post*               |
| Закрытые помещения (с артиклем)  | **in + Akk.**  | *ins Kino, in den Supermarkt*                |
| Домой (устойчиво)                            | **nach Hause** | *Ich gehe nach Hause.*                       |
| Дома (устойчиво)                              | **zu Hause**   | *Ich bin zu Hause.*                          |

**Ловушка:** *Ich fahre **in die** Stadt* (в город, внутрь) vs. *Ich fahre **zur** Stadt* (к городу, в направлении). Первое — стандарт .

---

### 6. Дополнительные пространственные предлоги (редкие, но встречаются)

| Предлог                 | Значение                  | Падеж      |
| ------------------------------ | --------------------------------- | --------------- |
| **oberhalb / unterhalb** | над / под                   | Genitiv         |
| **inmitten**             | посреди                    | Genitiv         |
| **diesseits / jenseits** | по эту / ту сторону | Genitiv         |
| **längs**               | вдоль                        | Genitiv / Dativ |

## II. Временные предлоги

### 1. Временные предлоги с Dativ

| Предлог     | Когда используется        | Пример                             |
| ------------------ | ------------------------------------------ | ---------------------------------------- |
| **an**       | дни, даты, части дня        | *am Montag, am 3. Mai, am Morgen*      |
| **in**       | месяцы, сезоны, «через» | *im März, im Winter, in einer Stunde* |
| **vor**      | «тому назад», «до»          | *vor einem Jahr, vor dem Essen*        |
| **nach**     | «после»                             | *nach der Arbeit*                      |
| **seit**     | «с» (продолжается)          | *seit einem Monat*                     |
| **bei**      | «во время»                        | *beim Essen*                           |
| **ab**       | «начиная с» (будущее)     | *ab morgen*                            |
| **zu**       | праздники                         | *zu Weihnachten*                       |
| **außer**   | кроме (время)                    | *außer montags*                       |
| **zwischen** | между (время)                    | *zwischen 8 und 9 Uhr*                 |

Источники:

**Слияние:** *am = an + dem, im = in + dem, beim = bei + dem*

---

### 2. Временные предлоги с Akkusativ

| Предлог  | Когда используется            | Пример             |
| --------------- | ---------------------------------------------- | ------------------------ |
| **um**    | точное время                        | *um 8 Uhr*             |
| **bis**   | «до» (конечный момент)       | *bis Montag*           |
| **für**  | «на» (длительность)            | *für eine Woche*      |
| **gegen** | «около» (примерное время) | *gegen 17 Uhr*         |
| **über** | «на» (период, разг.)             | *über das Wochenende* |

### 4. Особые случаи и контрасты

| Случай                                      | Правило                                                                    | Пример                       |
| ------------------------------------------------- | --------------------------------------------------------------------------------- | ---------------------------------- |
| Год без слова *Jahr*                 | без предлога и артикля                                         | *1918 endete der Krieg.*         |
| Год со словом *Jahr*                 | *im Jahr*                                                                       | *im Jahr 1918*                   |
| **vor** vs. **in** (контраст) | *vor einer Stunde* = час назад; *in einer Stunde* = через час | *Ich komme in einer Stunde.*     |
| **seit** vs. **vor**                  | *seit* = с (длится); *vor* = назад (точка)                   | *seit 2020* vs. *vor 3 Jahren* |

## III. Итоговая шпаргалка

| Категория                                      | Предлоги                                                                                                               |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Только Dativ**                            | aus, bei, mit, nach, seit, von, zu, außer, gegenüber                                                                         |
| **Только Akkusativ**                        | durch, für, gegen, ohne, um, bis, entlang                                                                                     |
| **Смешанные (Wo? = Dat / Wohin? = Akk)** | an, auf, hinter, in, neben, über, unter, vor, zwischen                                                                        |
| **Genitiv (книжные)**                      | wegen, trotz, während, statt/anstatt, innerhalb, außerhalb, oberhalb, unterhalb, inmitten, diesseits, jenseits, längs, nahe |
| **Время + Dativ**                            | an, in, vor, nach, seit, bei, ab, zu, außer, zwischen                                                                         |
| **Время + Akkusativ**                        | um, bis, für, gegen, über                                                                                                    |
| **Направление: nach**                  | города/страны без артикля                                                                                |
| **Направление: zu**                    | люди, учреждения                                                                                                 |
| **Направление: in + Akk.**             | страны с артиклем, закрытые помещения                                                          |
| **Устойчивые пары**                 | **nach Hause** (домой) / **zu Hause** (дома)                                                              |
