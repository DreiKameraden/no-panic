
# ИНФИНИТИВ С "ZU" И БЕЗ "ZU" — Компактная справка

## ГЛАВНОЕ ПРАВИЛО

Инфинитив **всегда в конце предложения**. Всё зависит от глагола перед ним.

---

## СВОДНАЯ ТАБЛИЦА

| Когда                                                                            | Zu?                                | Пример                                             |
| ------------------------------------------------------------------------------------- | ---------------------------------- | -------------------------------------------------------- |
| Модальные глаголы (müssen, können, wollen, sollen, dürfen, mögen) | ❌ **БЕЗ**                | Ich **will** Deutsch **lernen**.             |
| Вспомогательный *werden* (Futur)                                     | ❌ **БЕЗ**                | Er **wird** morgen **fahren**.               |
| Глаголы восприятия (sehen, hören, fühlen)                          | ❌ **БЕЗ**                | Ich **höre** ihn **singen**.                |
| Глаголы движения (gehen, fahren, kommen)                               | ❌ **БЕЗ**                | Wir **gehen** **schwimmen**.                 |
| *lassen, helfen, lehren, lernen*                                                    | ❌ **БЕЗ**                | Ich **lasse** das Auto **reparieren**.       |
| **Все остальные глаголы**                                    | ✅ **С zu**                 | Ich **versuche**, Deutsch **zu lernen**.     |
| Глаголы с отделяемой приставкой                           | ✅ **zu ВНУТРИ**       | Er **fängt an**, auf**zu**räumen.          |
| Цель (чтобы)                                                                 | ✅ **um ... zu**             | Ich lerne, **um** zu **arbeiten**.           |
| Без действия (не сделав)                                           | ✅ **ohne ... zu**           | Er ging, **ohne** sich zu **verabschieden**. |
| Вместо действия                                                         | ✅ **(an)statt ... zu**      | **Anstatt** zu **lernen**, spielt er.        |
| "Не нужно" (отрицание)                                                | ✅ **brauchen + nicht + zu** | Du **brauchst** nicht zu **warten**.         |

---

## КАК ОБРАЗУЕТСЯ "ZU + INFINITIV"

| Тип глагола                        | Форма                                                      | Пример                                                      |
| -------------------------------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------- |
| Обычный                               | **zu** + инфинитив (слитно)                | **zu machen**, **zu lernen**                          |
| С отделяемой приставкой | приставка + **zu** + корень (слитно) | **aufzumachen**, **einzukaufen**, **anzurufen** |
| На **-ieren**                        | **zu** + инфинитив (слитно)                | **zu studieren**, **zu telefonieren**                 |

---

## ИНФИНИТИВНЫЕ ОБОРОТЫ

| Конструкция               | Значение                       | Условие                                    | Пример                                                          |
| ------------------------------------ | -------------------------------------- | ------------------------------------------------- | --------------------------------------------------------------------- |
| **um ... zu**                  | чтобы, для того чтобы | Подлежащее **совпадает** | Ich lerne Deutsch, **um** in Deutschland **zu arbeiten**. |
| **ohne ... zu**                | не сделав чего-либо    | Подлежащее **совпадает** | Er ging, **ohne** die Tür **zu schließen**.             |
| **(an)statt ... zu**           | вместо того чтобы       | Подлежащее **совпадает** | Er sieht fern, **anstatt** Hausaufgaben **zu machen**.    |
| **brauchen + nicht/kein + zu** | не нужно                        | Только **отрицание**         | Du **brauchst** das **nicht zu tun**.                     |

> ⚠️ **Важно:** Если подлежащее **разное** → используй придаточное с *damit*:
>
> - ❌ Ich lerne Deutsch, um mein Sohn arbeiten kann.
> - ✅ Ich lerne Deutsch, **damit** mein Sohn arbeiten **kann**.

---

## ПОЗИЦИЯ В ПРЕДЛОЖЕНИИ

```
[Позиция 1] + ГЛАГОЛ + [середина] + (zu) + ИНФИНИТИВ
                                              ↑
                                        ВСЕГДА В КОНЦЕ
```

**Примеры:**

- Ich **versuche**, das Problem **zu lösen**.
- Er **hat** keine Zeit, ins Kino **zu gehen**.
- Wir **planen**, nächstes Jahr nach Berlin **zu fahren**.

---

## БЫСТРАЯ ПРОВЕРКА

**Задай вопрос:** Какой глагол стоит перед инфинитивом?

```
Модальный / werden / восприятие / движение / lassen-helfen-lehren-lernen?
    ↓ ДА                              ↓ НЕТ
  БЕЗ zu                             С zu
```

**Глаголы с отделяемой приставкой?** → **zu** вставляется внутрь: *auf**zu**machen*

**Нужно выразить цель/замену/отсутствие?** → **um/ohne/anstatt ... zu**

---

## МИНИ-ШПАРГАЛКА ДЛЯ ЗАПОМИНАНИЯ

| Запомни                                    | Правило                                                   |
| ------------------------------------------------- | ---------------------------------------------------------------- |
| **Модальные = без zu**          | müssen, können, wollen, sollen, dürfen, mögen                |
| **Восприятие = без zu**        | sehen, hören, fühlen                                           |
| **Остальные = с zu**              | versuchen, planen, hoffen, vergessen, versprechen...             |
| **Отделяемая приставка** | zu ВНУТРИ: auf**zu**räumen, ein**zu**kaufen   |
| **um/ohne/anstatt**                         | только если подлежащее ОДНО И ТО ЖЕ |
| **brauchen**                                | только в ОТРИЦАНИИ: brauchst nicht zu...         |
