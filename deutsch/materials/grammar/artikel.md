# Артикль в немецком языке

## I. Определённый и неопределённый артикль

В каждой ячейке — **неопр. / опр.** артикль.

| Падеж    | maskulin    | neutrum     | feminin     | Plural   |
| ------------- | ----------- | ----------- | ----------- | -------- |
| **N**   | ein / der   | ein / das   | eine / die  | — / die |
| **G**   | eines / des | eines / des | einer / der | — / der |
| **D**   | einem / dem | einem / dem | einer / der | — / den |
| **Akk** | einen / den | ein / das   | eine / die  | — / die |

**Особенности:**

- В **Genitiv** мужской и средний род получают окончание **-(e)s** у существительного: *eines Mannes, des Kindes*.
- В **Dativ Plural** существительное получает **-n**, если ещё не имеет: *den Kindern, den Frauen*.
- У неопределённого артикля **нет Plural** — в множественном числе артикль отсутствует, отрицание образуется через **kein-**.

## II. Памятка: когда какой артикль

| Ситуация                                                                                                | Артикль                         | Пример                                                                          |
| --------------------------------------------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------- |
| Предмет упоминается **впервые**, слушателю неизвестен         | **неопределённый** | *Ich sehe **einen** Mann.* — Я вижу (какого-то) мужчину. |
| Предмет **уже известен** из контекста или упоминался ранее | **определённый**     | *Der Mann ist groß.* — (Тот) мужчина высокий.                    |
| Предмет **единственный в своём роде**                                        | **определённый**     | *die Sonne, der Mond, die Erde*                                                     |
| **Превосходная степень**                                                               | **определённый**     | *der beste Film, die schönste Stadt*                                               |
| **Порядковое числительное**                                                         | **определённый**     | *der erste Tag, das dritte Haus*                                                    |
| **Родовые понятия**, абстракции, вещества (в общем смысле)    | **определённый**     | *Der Mensch ist sterblich. Das Wasser ist kalt.*                                    |
| **Профессия, национальность, религия** после sein/werden               | **без артикля**        | *Er ist Lehrer. Sie wird Ärztin.*                                                  |
| **Множественное число** в неопределённом смысле                    | **без артикля**        | *Ich sehe Männer.* — Я вижу (каких-то) мужчин.                  |
| **Отрицание** при неопределённом артикле или без артикля    | **kein-**                        | *Ich habe **keinen** Hund. Das sind **keine** Kinder.*                  |
| **Притяжательные** (mein, dein, sein…) заменяют неопределённый       | **притяжательный** | *Das ist **mein** Bruder.*                                                    |

**Короткое правило:**

> **Неопределённый** — когда предмет **новый** для слушателя («один из многих»).
> **Определённый** — когда предмет **уже известен** или **единственный** («тот самый»).
> **Без артикля** — профессия/национальность после *sein/werden*, а также Plural в неопределённом смысле.
