### Правило: Perfekt (прошедшее время)

Perfekt используется для рассказа о том, что уже произошло (особенно в разговорной речи).

**А. Структура Perfekt**

Perfekt состоит из **двух частей**:

1. **Вспомогательный глагол** *haben* или *sein* (стоит на **втором месте**, спрягается).
2. **Причастие** (Partizip II) смыслового глагола (стоит в **конце** предложения).

**Схема:** `Подлежащее + haben/sein + ... + Partizip II.`

- Ich **habe** gestern zehn Stunden **gearbeitet**.
- Ich **bin** sehr müde **gewesen**.

**Б. Спряжение вспомогательных глаголов**

| Лицо      | haben           | sein           |
| ------------- | --------------- | -------------- |
| ich           | **habe**  | **bin**  |
| du            | **hast**  | **bist** |
| er / sie / es | **hat**   | **ist**  |
| wir           | **haben** | **sind** |
| ihr           | **habt**  | **seid** |
| sie / Sie     | **haben** | **sind** |

**В. Когда *haben*, а когда *sein*?**

- **haben** — с большинством глаголов (особенно переходными: *arbeiten, trinken, essen, nehmen*).
- **sein** — с глаголами движения (*gehen, fahren, kommen*) и изменения состояния (*aufstehen, einschlafen*), а также с глаголами *sein* и *bleiben*.

**Г. Образование Partizip II**

| Тип глагола                                      | Правило                                                       | Пример                                                                                  |
| ---------------------------------------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **Слабые**                                     | **ge-** + основа + **-t**                          | arbeiten → **gearbeitet**, kaufen → **gekauft**                                 |
| **Сильные**                                   | **ge-** + изменённая основа + **-en**    | trinken → **getrunken**, essen → **gegessen**, schlafen → **geschlafen** |
| **С неотделяемой приставкой** | **без ge-**, основа + **-t/-en**                | verschreiben → **verschrieben**, verstehen → **verstanden**                     |
| **С отделяемой приставкой**     | приставка + **ge-** + основа + **-t/-en** | aufstehen → **aufgestanden**, einkaufen → **eingekauft**                        |

> 💡 **Запомни:** у сильных глаголов причастие нужно запоминать — оно часто меняет гласную: *trinken → getrunken*, *essen → gegessen*, *schlafen → geschlafen*, *sein → gewesen*.

</details>

## 4. Диалог 2: У врача (Beim Arzt)

*Лео приходит к врачу. Врач осматривает его и даёт советы.*

> **Ärztin:** Guten Tag! Was **fehlt** Ihnen?

>
> **Leo:** Ja, ich **habe** zehn Stunden **gearbeitet**. Ich **habe** nur Kaffee **getrunken** und nicht viel **gegessen**.
>
> **Ärztin:** Das **ist** nicht gut. Sie **haben** eine Erkältung. Sie **müssen** im Bett **bleiben** und viel Tee **trinken**.
>
