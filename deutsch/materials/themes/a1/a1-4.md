# УРОК 4: Mein Zimmer (Моя комната)

**Уровень:** A1

**Тема:** Описание комнаты и мебели. Повторение: семья, профессия, еда и покупки.

**Грамматика:** Артикли (определённый и неопределённый) в Nominativ и Dativ. Предлоги места **in, an, auf, neben, vor, unter, über** + Dativ. Глаголы **stehen** (стоять) и **liegen** (лежать).

**Цель:** Уметь сказать, какая мебель есть в комнате и где она стоит.

## 2. Диалог: Лео показывает свою комнату (Leo zeigt sein Zimmer)

*Лео получил комнату на станции. Миа приходит посмотреть.*

> **Mia:** Hallo Leo! Das ist also dein Zimmer?
>
> **Leo:** Ja, das ist mein Zimmer. Es ist klein, aber gemütlich.
>
> **Mia:** Was ist das? Ist das dein Bett?
>
> **Leo:** Ja, das ist mein Bett. Es steht **an der** Wand.
>
> **Mia:** Und wo ist dein Schreibtisch?
>
> **Leo:** Mein Schreibtisch steht **neben dem** Fenster.
>
> **Mia:** Was steht **auf dem** Schreibtisch?
>
> **Leo:** **Auf dem** Schreibtisch stehen mein Computer und meine Lampe.
>
> **Mia:** Und wo sind deine Bücher?
>
> **Leo:** Meine Bücher stehen **im** Regal. (= in dem Regal)
>
> **Mia:** Hast du auch einen Schrank?
>
> **Leo:** Ja, ich habe einen Schrank. Er steht **in der** Ecke.
>
> **Mia:** Und was ist das auf dem Boden?
>
> **Leo:** Das ist mein Teppich. Er liegt **vor dem** Bett. Er ist bunt und weich.
>
> **Mia:** Und wo ist deine Tasche?
>
> **Leo:** Meine Tasche liegt **auf dem** Sofa. Das Sofa steht **unter dem** Fenster.
>
> **Mia:** Dein Zimmer ist sehr ordentlich! Wo ist dein Handy?
>
> **Leo:** Mein Handy liegt **auf dem** Tisch. Der Tisch steht **zwischen dem** Bett und dem Sofa.
>
> **Mia:** Und was ist das **über dem** Bett?
>
> **Leo:** Das ist ein Foto. Es hängt **über dem** Bett. Das ist ein Foto von meiner Familie.
>
> **Mia:** Oh, sehr schön! Dein Zimmer ist wirklich gemütlich, Leo!
>
> **Leo:** Danke! Ich bin sehr zufrieden.

*(Словарь к диалогу: also = итак, gemütlich = уютный, das Bett = кровать, der Schreibtisch = письменный стол, das Fenster = окно, die Lampe = лампа, das Regal = полка, der Schrank = шкаф, die Ecke = угол, der Teppich = ковёр, weich = мягкий, bunt = яркий, die Tasche = сумка, das Sofa = диван, ordentlich = аккуратный, das Handy = мобильный телефон, der Tisch = стол, zufrieden = довольный)*

## 3. Наблюдай и выводи правило (Beobachte und entdecke die Regel)

*Перед сущетсвительным в немецком языке всегда идет артикль - он определяет род, число и падеж существительного. Посмотри на выделенные артикли после предлогов. Попробуй сам ответить: какой артикль стоит после предлога у мужского рода? А у женского? А у среднего?*

### Вопросы к наблюдению (Arbeitsfragen)

4. Какой артикль стоит после предлога у **среднего** рода? (*das Fenster → ?*)
5. Что происходит с **in + dem**? Какое сокращение ты видишь в диалоге? (*im Regal*)

### Правило: Артикли и предлоги места + Dativ

**А. Что такое артикль и зачем он нужен?**

В немецком перед почти каждым существительным стоит **артикль**. Он показывает:

- **род** существительного (мужской, средний, женский);
- **число** (единственное или множественное);
- **падеж** (кто? кого? кому? и т.д.).

**Два вида артикля:**

- **Определённый** (der / das / die) — «тот самый», о конкретном, уже известном предмете: *Das ist **der** Stuhl. **Der** Stuhl ist neu.*
- **Неопределённый** (ein / eine) — «один / какая-то», о новом, неизвестном предмете: *Das ist **ein** Stuhl. Ich habe **einen** Stuhl.*

**Падежи в немецком (пока изучаем два):**

- **Nominativ** (N) — кто? что? (подлежащее: *Der Tisch ist groß.*)
- **Dativ** (D) — кому? где? (после предлогов места: *auf **dem** Tisch*)
- Genitiv (G) и Akkusativ (Akk) — изучим позже.

**Б. Определённый артикль (der / das / die) по падежам**

| Падеж    | maskulin      | neutrum       | feminin       | Plural        |
| ------------- | ------------- | ------------- | ------------- | ------------- |
| **N**   | **der** | **das** | **die** | **die** |
| **G**   |               |               |               |               |
| **D**   | **dem** | **dem** | **der** | **den** |
| **Akk** |               |               |               |               |

**В. Неопределённый артикль (ein / eine) по падежам**

| Падеж    | maskulin        | neutrum         | feminin         | Plural |
| ------------- | --------------- | --------------- | --------------- | ------ |
| **N**   | **ein**   | **ein**   | **eine**  | —     |
| **G**   |                 |                 |                 |        |
| **D**   | **einem** | **einem** | **einer** | —     |
| **Akk** |                 |                 |                 |        |

> 💡 **Запомни:** в Dativ у мужского и среднего рода артикль **dem / einem**, у женского — **der / einer**, во множественном числе — **den** (неопределённого артикля во множественном числе нет).

**Г. Предлоги места + Dativ (Wo? — Где?)**

После предлогов места **in, an, auf, neben, vor, unter, über, zwischen, hinter** существительное стоит в **Dativ**. Эти предлоги отвечают на вопрос **Wo?** (Где?).

**Сокращения:**

- **in + dem = im** (im Regal)
- **an + dem = am** (am Fenster)

**Д. Глаголы:**

- **stehen** (стоять) — для вертикальных предметов: Das Bett **steht** an der Wand.
- **liegen** (лежать) — для горизонтальных предметов: Das Handy **liegt** auf dem Tisch.

</details>

## 4. Шпаргалка: Как описать комнату (Das Zimmer beschreiben)

| Что сказать                      | Немецкий                      | Перевод                             |
| ------------------------------------------ | ------------------------------------- | ------------------------------------------ |
| Что где стоит?                  | Wo **steht**...?                | Где стоит...?                      |
| Что где лежит?                  | Wo **liegt**...?                | Где лежит...?                      |
| ... стоит у стены               | ... steht **an der** Wand       | ... стоит у стены               |
| ... стоит рядом с окном    | ... steht **neben dem** Fenster | ... стоит рядом с окном    |
| ... лежит на столе             | ... liegt **auf dem** Tisch     | ... лежит на столе             |
| ... стоит в углу                 | ... steht **in der** Ecke       | ... стоит в углу                 |
| ... лежит перед кроватью | ... liegt **vor dem** Bett      | ... лежит перед кроватью |
| ... стоит на полке             | ... steht **im** Regal          | ... стоит на полке             |

## 6. Домашнее задание (Hausaufgabe)

**Задание:** Напиши короткий текст (5–6 предложений) о своей комнате.
Используй план ниже:

1. **Комната:** Mein Zimmer ist... (groß/klein/gemütlich).
2. **Мебель:** Ich habe einen... / eine... / ein... (Bett, Schreibtisch, Schrank, Sofa).
3. **Расположение:** Mein Bett steht... (an der Wand / neben dem Fenster).
4. **Вещи:** Meine Bücher stehen... (im Regal / auf dem Tisch).
5. **Описание:** Mein Teppich ist... (bunt/weich).

*Пример:*

> Mein Zimmer ist klein, aber gemütlich. Ich habe ein Bett, einen Schreibtisch und einen Schrank. Mein Bett steht an der Wand. Mein Schreibtisch steht neben dem Fenster. Meine Bücher stehen im Regal. Mein Teppich liegt vor dem Bett. Er ist bunt und weich. Ich mag mein Zimmer sehr.
